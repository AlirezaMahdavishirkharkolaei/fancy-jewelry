# Brand assets

- `logo.cdr`: original CorelDRAW logo of Fancy Diamonds & Jewelry.
- `../assets/img/logo.svg`: gold vector version, converted from the CDR. Use it for print and social media.
- `../assets/img/logo-sprite.svg`: the same vector as an SVG `<symbol>`. The site uses it so that the logo colour follows CSS `color`.

The logo belongs to Fancy Diamonds & Jewelry and is used here with the shop's agreement.
